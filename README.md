# Electronic Keyboard (Model EK-1)

Development version **0.9.8**. A 49-key browser instrument inspired by classic home keyboards, with 12 classic voices, eight original six-operator FM voices, six rhythms, five original demos, MIDI playback, and a four-part Song Builder. No affiliation with Casio or Yamaha.

## Start playing

Extract the whole ZIP and open `index.html` in a current browser. No local server, installer, account, network access or terminal is required. Keep the supporting files next to the HTML file. Click a key to enable audio. Computer keys Z through M and Q through U play two octaves from F3 to E5; C = A3, V = B3, B = middle C (C4). The on-screen keyboard spans C3 to C7. The upper and lower plastic rails show every actual note name. Use comma and period, or the octave buttons, to shift computer-key shortcuts down or up one octave (lower: C3-E4, default: F3-E5, upper: F4-E6; notes below the displayed range are unavailable). Mouse/touch keys and imported MIDI pitches stay fixed. Mobile horizontal scrolling is independent. Expand Song Builder or Sound options when needed; both start collapsed.

## Instruments and SoundFonts

Choose a Classic or FM voice in VOICE. FM offers brightness, attack and release. Use OPEN SOUNDFONT to open a local SF2/SF3 bank (maximum 512 MiB). No SoundFont is included. [FluidR3 GM](https://www.pianobooster.org/download.html) by Frank Wen is the recommended optional download (148 MB, MIT). Extract the downloaded bank if necessary, then open the SF2 file with the file picker. Imported SoundFonts stay available while switching Classic or FM voices. MIDI playback, all five built-in demos and composition use a loaded SoundFont, otherwise the built-in approximations. Original demo melodies, rhythms and chords are preserved, with GM lead, chord, bass and drum channels. MELODY OFF immediately silences the sampled lead while accompaniment continues. The demo lead follows the selected Classic, FM or SoundFont voice by default, while backing instruments keep their original assignments. Disable this in Sound options for the original demo lead. MIDI and Song Builder playback remain independent of the live voice. A narrow or non-GM bank may substitute instruments for missing presets. PAUSE/RESUME freezes the audio clock for demos, rhythms, MIDI, Song Builder and recorded playback. While paused live keys are silent; STOP ends playback and silences held SoundFont notes. Active recording and offline export are not pausable. Bank files are never uploaded. Expand Sound options to favourite the currently selected instrument, recall favourites, or add room reverb and chorus. Both effects default to off and pass through the existing protected output stage. They apply to live playback and WAV/MP3 export; MIDI and project files do not store these global session settings. SoundFont favourites are cleared when the bank is removed or replaced. Built-in favourites last until the page is closed or reloaded. Loading large banks, especially compressed SF3, can use more memory than the file size.

## Song Builder

Choose a style, feel, key, pattern and length, then NEW ARRANGEMENT. Natural (default) adds deterministic humanisation, style-specific swing, recurring melodic motifs, close chord inversions, bass movement, drum fills and style-appropriate General MIDI instruments. Expressive increases timing and velocity variation and adds denser fills. Original preserves the previous arrangement engine, including playback of projects saved before v0.9.2. Existing notes are not regenerated when changing feel; use NEW MELODY to replace the melody while retaining chords, or NEW CHORDS + MELODY to cycle to a different chord pattern and regenerate both while retaining sections and mixer settings. PLAY SONG returns to the instrument by default; uncheck Return to keyboard on playback to stay in Song Builder. Main volume starts at 25%, with conservative FM and SoundFont trims and a shared compressor and final sample-peak ceiling. The protected mix has extra linear headroom before its emergency limiter; demo backing and lead levels are reduced, and the local SoundFont buffer is 2048 frames (higher latency, potentially fewer dropouts). A digital ceiling cannot guarantee safe headphone loudness; keep your device volume low when auditioning. Edit individual chords and melody notes, mute or change instruments, adjust track levels and pan, and append labelled sections up to 64 bars. Use the compact Song Structure buttons to jump to a section; Duplicate Section copies its notes and chords immediately after it. The melody editor can be collapsed. Undo and Redo keep up to 40 committed edits, including arrangement changes, notes and section operations; opening a project resets history. A rest is silent; Hold extends the preceding note. New melody generates variations. Save and reopen editable `.ek1` projects; replacing an edited project prompts you to save first. Projects store the bank filename, not the actual samples. Reopen the bank to reproduce the original instruments.

Export a multitrack MIDI file or stereo audio using the actual selected bank. WAV: 44.1/48 kHz, 16/24-bit PCM. MP3: 128/192/256/320 kbps. Rendering is local and cancellable; classic OfflineAudioContext rendering may finish its current render before cancellation takes effect. Audio exports are limited to five minutes and include a two-second release tail. Live FM and accompaniment are not recorded into Song Builder audio. Imported MIDI defaults to its original channel instruments. After opening a MIDI, choose MIDI VOICE: Original instruments, All melodic channels, or one channel. The selected VOICE then applies to subsequent notes on those channels during playback, including Classic, FM and SoundFont voices; drums and the saved MIDI copy are unchanged. Song Builder playback and exports retain their own instruments. MIDI playback highlights the displayed pitched keys by channel, using split colours for shared pitches; the channel legend identifies patches by GM program number. Percussion and notes outside the 49-key range do not light keys. MIDI import supports formats 0 and 1, up to 8 MiB and 30 minutes, with tempo changes, channel volume, pan, expression, sustain and program/bank selection. Full GM/GS/XG controllers, pitch bend, hardware MIDI, DX7 SysEx and arbitrary MIDI song editing are not implemented.

## Offline architecture and licensing

The runtime is an ordinary set of HTML, CSS and JavaScript files, not a server application. The SpessaSynth local bridge replaces the AudioWorklet entrypoint with a legacy ScriptProcessorNode for file:// compatibility. This may use more main-thread CPU and have higher latency. Browser support varies; direct local-file navigation is a release test requirement.
